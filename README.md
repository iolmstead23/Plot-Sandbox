# Plot-Sandbox

This project is a lightweight Python toolkit for visualizing 3 dimensional plots. The project is designed to be a visual aid to see how nodes interact under different forces. It can also be used as a tool to compare the same set of elements under different applied forces. The main goal is to understand how data interacts within a vector space to study how spaces compress elements under different conditions. The outcome would be to find harmony within a system so that the result is a stable state with no residual potential energy within the system.

## Instructions

run `python main.py` to run the full UI
run `python main.py --cli` to run in CLI mode
run `python main.py --source linear` or `python main.py --source weighted` to use a specific datasource
