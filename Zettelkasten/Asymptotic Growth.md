Asymptotic growth analyzes how functions behave as input size approaches infinity, often using notations like Big O (upper bound), Omega (lower bound), and Theta (tight bound). These relate to asymptotes, which are limiting lines curves approach. For example, Big O describes the worst-case growth rate, similar to how an asymptote bounds a curve's approach.

Common notations include Big O for upper bounds, Omega for lower bounds, and Theta for tight bounds. Examples range from constant time (O(1)) to exponential time (O(2^n)), with linear (O(n)) and quadratic (O(n^2)) being frequent cases that highlight the importance of choosing efficient algorithms.

> [!info] Key Concepts

> - **Upper bound**: Big O notation, e.g., $O(n^2)$.

> - **Lower bound**: Omega notation, e.g., $\Omega(n)$.
